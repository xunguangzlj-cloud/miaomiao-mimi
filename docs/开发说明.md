# 开发说明

入口为 `game.js`，启动资源准备完成后进入游戏。网页使用同一组模块，由 `tools/build-preview.cjs` 生成 `web/preview.js`。

## 数据与平台

棋局、道具、设置、资料和打卡保存在当前设备。提示与助手在北京时间每日零点补满各3次，切换关卡不补次数。旧存档标识保留兼容，新项目不应随意替换存储键。

微信好友排行由开放数据域处理，使用微信云存储同步成绩；不会恢复本机棋局。开启排行榜前需在自己的平台账号配置相应能力、隐私指引和授权。

## 资源与打包

普通分包分别承载动物表情、界面纹理、庆祝图、音乐、启动资源和盆栽。资源失败时使用基础画面，音乐默认关闭，需要真实用户操作后播放。设置页与后台暂停计时和相应播放。

`npm run check:package` 按工程配置统计未压缩主包、分包及总包，实际上传结果以微信开发者工具为准。说明、测试、工具和网页预览不进入微信运行包。

## 关卡维护

`src/level-data.js` 为当前99关，`src/levels.js` 用于已有棋局兼容。`tools/generate-levels.cjs` 会改写兼容关卡文件，运行前先备份；`tools/profile-levels.cjs` 用于统计难度。修改关卡后需同步校验记录，并运行全量测试。

## 验证范围

自动测试覆盖逻辑、关卡、提示、计分、存档、界面布局、音频事件、打卡与开放数据域。测试替身不能验证真实好友数据、设备音量、震动、平台审核或网络条件；发布前应使用自己的账号完成真机验收。
