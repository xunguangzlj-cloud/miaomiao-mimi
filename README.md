# 喵喵谜谜小屋

<img src="splash-assets/garden-logo.png" alt="喵喵谜谜小屋" width="240">

一款猫咪主题的逻辑解谜小游戏。观察颜色区域，给每只小动物找到恰到好处的位置。

原生 JavaScript 与 Canvas 2D 实现，同时支持微信小游戏工程和浏览器预览，运行不依赖第三方库。

## 玩法

- 每行、每列、每个颜色区域各放置一只动物。
- 动物之间不能上下、左右或对角相邻。
- 单击打叉，双击放置；手指滑动可连续打叉，也能切换放置模式。
- 错误放置扣除生命；找齐棋盘上的动物即可通关。

## 功能

| 内容 | 说明 |
| --- | --- |
| 关卡 | 99关，4×4至9×9；附独立新手教学 |
| 辅助 | 提示与猫咪助手每日各3次，最多储存各3次 |
| 成绩 | 正确放置、手动连击、通关时间与无误表现共同计分 |
| 打卡 | 连续打卡、盆栽成长与七日神秘礼盒 |
| 外观 | 8类动物、12种小屋主题、8种头像框，随等级解锁 |
| 排行榜 | 微信好友成绩排行；网页显示本机成绩 |
| 设置 | 音乐、音效、震动与图案模式独立开关 |
| 存档 | 本机保存棋局、打卡、资料与设置 |

## 浏览器预览

需要 Python 3。服务根目录必须是项目根目录：

```sh
python -m http.server 18775 --bind 127.0.0.1 --directory .
```

打开 <http://127.0.0.1:18775/web/>。好友排行榜依赖微信环境，浏览器预览不提供微信好友数据。

## 导入微信开发者工具

1. 下载或克隆本仓库，在微信开发者工具中导入项目根目录，选择小游戏。
2. 工程默认使用游客配置；使用好友排行榜和代码上传时，将 `project.config.json` 中的 `appid` 改为自己的小游戏 AppID。
3. 编译后在 Android 与 iOS 微信内核对触摸、声音、震动、分包和授权流程。

公开仓库不含平台账号资料、上传密钥或个人备案材料。导入工程与正式发布是不同步骤，发布还需完成自己账号的资料与审核。

## 开发与检查

需要 Node.js 20或更新版本，无需安装运行依赖。

```sh
npm test
npm run build:preview
npm run check:package
```

修改 `src/` 后重新构建网页预览。关卡测试包含独立求解、唯一解、连通性、对称去重以及提示完成路径检查。
